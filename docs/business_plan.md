# **Monetization outline**

- Free tier with up to N cards and basic share links
- Plus plan with unlimited cards, albums, PDF export, and priority OCR
- One-off paid exports: hardcover album of a selected set
- Premium features roadmap: collaborative albums, memorial reels, print photobooks

# **Differentiation from generic photo apps**

- Card-aware scanner flow
- Handwriting-first transcription and search
- People- and event-centric organization out of the box
- Rituals that resurface meaning (e.g., “Today in Cards,” memory reels)
- More humanistic framing of cards as memories, not just images

# **Launch plan**

- **Private beta** with 25 families covering different use cases
- **Concierge onboarding** with a starter kit: scan 10 cards in 10 minutes
- **Feedback loop inside the app** with quick surveys after key actions
- **Event-based seeding**: weddings, baby showers, graduations, memorials (life events where cards pile up fast)
- **Partnerships** with stationery shops, photographers, and professional organizers for referral bundles
- **Campaign concept**: *“Goodbye clutter, keep the love”* as a simple, emotional hook to drive initial uploads
- **Concierge test** extension: offer to digitize 10–20 cards manually for new users, then show them the archive to create delight and habit

**Go-to-Market (early ideas)**

- Focus on life events with many cards: weddings, baby showers, graduations, memorials
- Partnerships with stationery shops, event photographers, and organizers
- Campaign concept: *“Goodbye clutter, keep the love”*

# **Roadmap after V0**

- Memory reels and resurfacing rituals by date or person
- Collaborative albums for families
- Print books and high quality exports
- Memorial mode for a loved one’s messages

# **Open questions**

- Will users want import from existing photo libraries
- Which OCR provider performs best on cursive handwriting
- Should we support Android in the first quarter

# **Naming options**

Keepsake, Kindred, CardVault, Ink & Echo, Paperlight, Heartline, Memento

# **Next steps**

- Turn wireframes into clickable prototype
- Source 50 benchmark cards and create ground truth set
