# Improve Add Card UX/UI

Status: To do
Priority: Must have

### Adding a Card flow

- WEB - Once an image is captured or uploaded on the first step, that captured image should be shown as captured and the option to edit/remove should persist throughout the following steps. In other words, no matter what step you get to, you shouldn’t have to “go back” to a previous pages to make adjustments - the page should be acommodating of actions.
- MOBILE -
- Visual progress needs to be more apparent. This can perhaps simply be factored in with the above feedback.
- Pressing the back button shouldn’t erase the first image added/start the first step all over again
- The CTAs do not need to extend all the way across the screen. They should be appropriately sized in accordance with standard UX/UI design principles.
